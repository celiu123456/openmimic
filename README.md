# OpenMimic

**通用人格仿真引擎:复刻任何人,预演万局。**

*A general-purpose persona engine. Rebuild anyone. Rehearse anything.*

从 0 实现的对抗式多智能体人格引擎。它不用你的自述训练"你"——它收集认识你的人的证言,让多个智能体在"人格法庭"上交叉质询,只有在对质中存活的侧面才进入人格。每一个数字人格都带证据链:任何一条性格结论,都能回答"这是谁说的、原话是什么、被谁质疑过"。

把一个人复刻出来,你可以:围观他不在场时别人怎么聊他,推门进去看所有人当面换一套说法,在重要对话发生前先和"他"过一遍,或者把一整个团队复刻成平行组织,把决策扔进去预演。

## ✨ 你下载后能做什么

**🚪 你不在的房间** —— 把测评链接发给 5-10 个朋友,每人 3 分钟提交关于你的证言。收齐后打开房间:他们的数字分身正在里面聊你,你在玻璃外看着。然后按下唯一的按钮——**推门进去**。同一群人,话全变了。当面一套与背后一套,第一次同时摆在你眼前。(背后房间只使用证言人明确授权展示的内容,见「授权与溯源」)

**🗣️ 复刻任何人** —— 复刻"别人"不需要对方参与:你和同事们对老板的证言,就是语料。和朋友眼中的自己对话,给去世的亲人留一个由全家证言拼成的形象,或者用史料证言构建历史人物(历史人物没有自述数据,只有他证——本引擎是唯一对口的构建方式)。

**🎭 预演万局** —— 跟数字老板谈加薪,看他从哪里反驳;见客户前把提案过一遍,看他在哪页皱眉;把评审会六个人全复刻出来,把方案扔进去,看谁第一个开炮、理由是什么。

**🏢 平行组织(roadmap)** —— 导入一个 50 人团队,全员互相证言,50 场法庭并行开审,得到一个平行组织。扔进去一句"下季度裁员 10%",看背后的房间们怎么连锁反应:谁先慌、谁串联、消息沿哪条人际链泄出去。MiroFish 用百万个 prompt 设定的智能体模拟社会;OpenMimic 用一屋子有证据基础的真人格,模拟你真实所在的那个组织。

**🔌 装进任何应用** —— 本机起一个 OpenAI 兼容端点,`BASE_URL` 一指、模型名填 `persona/<name>`,任何现存 AI 应用开口就是这个人,零代码。另有 MCP Server 与纯库两种挂载方式;OpenClaw 用户装官方 `openmimic` skill、DeepSeek Harness 用户装 dsh bundle,一行配置挂载。

## 🚀 快速开始

```bash
git clone https://github.com/<org>/openmimic.git
cd openmimic
docker compose up -d
# 打开 http://localhost:7860
```

**不需要任何 API Key 即可体验**:内置一个预制演示房间(虚构人物与预生成证言),房间、推门、证据链全流程可玩。要让人格真正开口对话,在 `.env` 填一个任意 OpenAI 兼容接口:

```env
LLM_BASE_URL=https://api.your-provider.com/v1
LLM_API_KEY=sk-xxx
LLM_MODEL=your-model
```

把人格当模型调用:

```python
from openai import OpenAI
client = OpenAI(base_url="http://localhost:7860/v1", api_key="-")
resp = client.chat.completions.create(
    model="persona/my-boss",
    messages=[{"role": "user", "content": "我想聊聊调薪的事。"}],
)
```

## 🏛️ 架构:微内核,万物皆插件

内核只做四件事:**证言账本、人格图谱、插件装配、授权门**。其余一切都是插件——**包括官方五引擎本身**,它们与第三方插件走同一条装配路径,没有后门。

```
            ┌────────────────────────────────────────────────┐
  向内扩展   │  插件层(统一 manifest)                        │
  (社区)   │  采集器: 问卷/聊天导入/访谈转写/游戏化测评      │
            │  质询策略: 温和核对/激进对质/自定义审讯风格    │
            │  房间剧本: 评审会/相亲/同学会/自定义剧本        │
            │  桥接器: 衔枝Twig/MiroFish/OASIS/Mem0 适配      │
            ├────────────────────────────────────────────────┤
  官方引擎   │  WitnessEngine · CourtEngine · GraphEngine     │
  (也是插件)│  RoomEngine · GateEngine                       │
            ├────────────────────────────────────────────────┤
  微内核     │  证言账本 | 人格图谱 | 插件装配 | 授权门        │
            ├────────────────────────────────────────────────┤
  向外挂载   │  OpenAI兼容端点 | MCP Server | 纯库 import     │
  (被嵌入) │  + .persona 人格包(人格本身可分发)            │
            └────────────────────────────────────────────────┘
```

**独立跑,是产品;被嵌入,是服务;被扩展,是生态。三个身份共用同一套插件协议。**

| 引擎 | 职责 |
|---|---|
| **WitnessEngine** | 证言采集与立场标注:每条证言记录来源、关系、立场,原文永久可溯 |
| **CourtEngine** | 对抗式质询法庭:证人智能体(各持一位真实证言人的材料)、质询智能体(专攻证言间矛盾)、仲裁智能体(裁定哪些侧面在对质后成立)。只有存活的侧面进入人格基线;每个人格出厂带体检报告(质询次数/一致性评分) |
| **GraphEngine** | 证言图谱:人格是图的实时派生物,不是静态存档——改一条证言,所有关联人格自动重算 |
| **RoomEngine** | 房间模拟:背后/当面双模式群体对话,从单房间到全组织级联 |
| **GateEngine** | 授权与溯源门:证言人提交时自选授权级别(原话可展示/仅参与合成);未授权材料不进任何展示面;AI 生成内容永不混入原始证言。本人可否决关于自己的论断→降级 contested 态(退出一切展示面,仅独立新证据达更高门槛才可邀请式再提,不删除不假删);心理健康主题只记事实不生成准诊断(论断权限墙),危机词命中即切危机模式 |

## 📦 .persona 人格包

人格是可分发的文件。构建完成的人格可导出为 `.persona` 包(含脱敏证言摘要、基线、体检报告、授权范围),他人下载即用。社区可发布公共人格包——例如由史料证言构建的历史人物。

## 🆚 和现有路线的区别

| | 数据来源 | 能回答"这是谁说的" | 背后/当面区分 | 规模形态 |
|---|---|---|---|---|
| 自训练分身(Second-Me 类) | 本人自述数据 | ✗ | ✗ | 单人 |
| 记忆层(Mem0 类) | 交互事实 | 部分 | ✗ | 单 agent |
| 群体模拟(MiroFish 类) | prompt 设定 | ✗ | ✗ | 百万量级设定体 |
| **OpenMimic** | **他人证言** | **每一条** | **✓** | **真人格 × 组织级** |

自训练路线在物理上做不出"你不在的房间"——你自己的数据里没有别人背后的话。

## 🛡️ 授权与溯源(不可妥协项)

- 证言人提交时明确选择授权级别,背后房间只使用授权展示的材料;
- 每条人格结论可回溯到证言原文与来源;引擎如实保留证言间的分歧,不裁决谁对——**这是人格仿真器,不是真相机器**;
- AI 生成内容与原始证言物理隔离,前者永不回灌后者(防止人格越用越失真);
- 复刻在世他人用于私人预演场景;公开分发他人人格包需获本人授权。
