# OpenMimic 评测账簿

## 口径声明 (v1)

- **裁判模型**: 由运行时 `.env` 的 `LLM_MODEL` 指定
- **裁判 Prompt SHA-256**: 见各条目；prompt 变更必须另起口径节
- **成对盲评方法**: 给定真实回答 R 与两个候选 A/B，裁判判断哪个在内容上更接近 R；每对跑两次（位置互换），两次不一致则该对作废，不进分子也不进分母
- **有效对**: 两次位置互换结论一致的对数
- **作废对**: 两次位置互换结论不一致、或解析失败的对数
- **胜率**: 有人格预测胜出的有效对数 / 有效对总数
- **Wilson 95% 区间**: Wilson score 置信区间，z=1.96
- **位置偏置**: 作废对数 / 总对数
- **稳定度重合率**: 同一数据重复 K 次法庭后，存活论断按字符二元组 Jaccard (阈值 0.5) 做贪心匹配，报告所有 C(K,2) 对的平均重合率 +/- 标准差
- **证人数曲线**: 对 n=2..N 的证人子集各取至多 maxSubsets 个随机子集，报告各 n 的稳定度
- **作废规则**: 位置互换不一致 → 作废；LLM 解析失败重试一次后仍失败 → 作废
- **注意**: 林默为手写虚构演示数据，仅验证管线，不代表真实保真度
